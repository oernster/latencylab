Running from source

You do not need to. The installers above are the same application, and nothing about the tool assumes a checkout. This is here because the engine is a Python library with a CLI in front of it, so some people would rather drive it that way or read it before running it.

# Clone and install (dev)
git clone https://github.com/oernster/latencylab.git
cd latencylab
python -m pip install -e .[dev]
python -m pip install -r requirements.txt

# Run the desktop UI (client of the headless core)
python -m latencylab_ui

# Run the test suite (the strict 100% coverage gate is built in)
python -m pytest
